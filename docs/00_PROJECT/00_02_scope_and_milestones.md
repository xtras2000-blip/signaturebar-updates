# 00_02 Scope and Milestones

## 1. 콘텐츠 범위

- **플레이 기간**: 아이 출생 직후(0세)부터 초등학교 입학(만 7세)까지.
- **성장 챕터**: 5개 챕터로 분할한다.

| 챕터 | 시기 | 핵심 테마 |
|---|---|---|
| CH1 | 0~12개월 | 생존과 수면 부족 |
| CH2 | 1~3세 | 첫 말, 첫 걸음, 자아의 등장 |
| CH3 | 3~5세 | 어린이집, 사회성의 시작 |
| CH4 | 5~6세 | 또래 관계, 비교와 불안 |
| CH5 | 6~7세 | 초등학교 입학 준비, 독립의 예감 |

## 2. 범위 제외 (Out of Scope, v1)

- 멀티플레이, 온라인 기능
- 아빠/조부모 플레이어블 캐릭터 (NPC로만 등장)
- 판타지·초자연 요소
- 7세 이후 콘텐츠 (v2 후보로 99_ARCHIVE에 아이디어만 보관)
