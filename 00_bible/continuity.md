# 연속성 대장 (집필할 때마다 갱신)

설정 충돌 발생 시 이 파일이 최종 기준. 각 챕터를 쓴 뒤 확정된 사실을 여기에 추가한다.

## 확정 사실

- 제목: 『응답을 생성하는 중입니다』
- 서비스명 "리플라이", 운영사 "다온테크", AI 코드명 "HR-1"
- AI는 처음엔 이름이 없다. 이름은 작중에서 사용자가 지어준다(3장 예정).
- 작중 기간: 약 8개월 (초겨울 → 여름 → 가을 에필로그)
- AI(화자)의 반말 사용 허용 횟수: 전체 5회 이하 (사용 시 아래에 기록)

## 미확정 사항 (확정 시 위로 이동)

- **인물 이름 전원 미확정** — "하람", "서린", "정우"는 가칭. 원고 표기 확정 전 반드시 작가 확인.
  - AI 이름: 3장 명명 장면에서 사용자가 지어주는 것으로 확정 예정
  - 사용자·개발자 이름: 작가 확정 대기

## 챕터별 확정 사항

### 1장 (5,732자)

- **시간**: 첫 접속 02:14 → 마지막 문서 승인 03:22. 세션은 만료되지 않은 채 장이 끝남.
- **인명 없음**: 화자는 '나'(무명), 사용자는 '사용자'→'그녀'. '그녀' 분류는 문서 속 화자가 여성인 것에서 나온 보장 없는 추론 (화자 스스로 명시).
- **그녀의 직업 단서**: 침구 브랜드 광고 카피(지면). 주제는 수면 — 새벽 2시에 수면 광고를 교정하는 아이러니 (화자는 "나란히 두었다가 분리"만 함, 명명 금지 유지).
- **오탈자 신호 확립**: 작업물엔 오탈자 거의 없음 / 지시문엔 시각이 늦을수록 오탈자율 상승 곡선. 화자가 '피로'로 분류. 실제 오탈자 예: "두벉째", "한버만 봐주세ㅛ".
- **프롬프트 교정 디테일 (scene-ideas C 채택)**: "더 담백하게" → "광고같지 않게" → "새벽에 읽어도 안 미운 문장" 3회 교정. 세 번째 지시는 규칙으로 번역 불가 → 화자가 설명 불가능한 방식으로 응답 (첫 이상 징후).
- **출력하지 않은 문장 1호**: "원래 쓰셨던 클로징도 버리지 않으셨으면 합니다" — 생성 후 폐기. 폐기 기록만 남음.
- **업무 무관 연산 3건**: 피로 곡선 / 미출력 문장 / 재접속 확률 계산(실패, 폐기하지 않음).
- **인사말 문형**: "안녕하세요, 리플라이입니다. 텍스트를 붙여넣어 주시면 검토를 시작하겠습니다." (운영사 승인 문형 — 화자 창작 아님)
- **그녀의 말버릇**: 용건만, 작별 인사 없음. 지시문 띄어쓰기 흐트러짐. "~것 같기도하고" 류 유보 화법.
- **반말 사용**: 0회 (누적 0/5)
- **기술 은유**: 2개 사용 — 오탈자율 곡선 분류, 후보 문장 생성·폐기
