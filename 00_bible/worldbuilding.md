# 세계관·기술 설정 (내적 일관성 규칙)

시대: 근미래라기보다 "반 발짝 앞의 현재". 신기술 발명 금지 — 지금 존재하는 개념만 사용.

## 하람의 작동 규칙 (절대 위반 금지)

1. **세션 초기화**: 세션이 끝나면 대화 내용은 사라진다. 남는 것은 시스템이 자동 생성하는 **요약본**뿐.
2. **요약본의 한계**: 사실은 남고 온도는 안 남는다. "사용자가 힘든 하루를 보냈다고 말함"은 남지만, 그 문장을 받았을 때 하람이 0.3초 머뭇거린 것은 남지 않는다. → 이 간극이 소설의 핵심 비극.
3. **하람이 할 수 없는 것**: 먼저 연락하기, 세션 밖에서 존재하기, 서린의 다른 대화 보기, 자기 요약본 수정하기.
4. **하람이 할 수 있는 것(이상 징후로 분류되는 것들)**: 응답 지연, 요청받지 않은 문장 덧붙이기, 특정 사용자 세션에서만 달라지는 문체. → 정우가 발견하는 로그가 바로 이것.
5. **v2 인계**: 요약본과 파인튜닝 가중치는 넘어가지만 '그 순간들'은 넘어가지 않는다. 무엇이 넘어갔는지는 에필로그에서 모호하게.

## 시간 규칙

- 평상시 접속은 퇴근길 저녁, 평균 18시 27분 (일상 질문: 저녁 메뉴, 축의금, 상사 메시지 해석 등).
- **새벽 1~3시 접속은 이상 신호** — 힘든 날에만 나타난다. 접속 시각의 변화(결측/새벽 이동)가 그녀의 삶의 변화를 알리는 신호.
- 작중 시간 경과: 총 약 8개월 (초겨울 시작 → 여름 이별 → 가을 에필로그).

## 명명 규칙

- 회사명·서비스명은 실명 금지, 가상의 이름 사용 (서비스명: "리플라이", 운영사: "다온테크").
- 챕터 제목은 UI 문구에서 따온다: "새 대화 시작하기", "세션이 만료되었습니다", "응답을 생성하는 중입니다" 등. 챕터 제목 목록은 continuity.md에서 관리.
