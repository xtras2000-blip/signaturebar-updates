# AURA 룰 v2 「이중생활」 — 플레이 룰의 재발명

기존 룰(에너지 램프 + 소환 + 공격)은 검증된 구조지만 하스스톤의 그림자가 짙다.
v2는 플레이어가 배우는 룰을 통째로 새로 발명한다. 설계 사상은 하나다:

> **"모든 카드는 두 얼굴을 가진다."**
> 캐릭터는 낮의 생활인과 밤의 대응관, 작전 카드는 펼치면 전술·엎으면 함정.
> 세계관의 "이중생활"이 곧 게임 규칙이다.

엔진 계약(황금률 / 이벤트 큐 / 일괄 판정, `rules.md` 0·3·5·7·8절)은 그대로
유지한다 — 바뀌는 것은 그 위에서 도는 플레이어 룰이다.

---

## 0. 3분 요약 (이것만 알면 첫 판 가능)

```
■ 목표      : 균열 코어 3개를 먼저 모으면 승리
■ 하루 구조 : 아침(1드로우) → 낮(카드 2장 플레이) → 밤(전투 1번) → 반복
■ 낮에 하는 일 (비밀리에 준비, 상대에게 안 보임)
   - 캐릭터를 "대기조"에 올린다
   - 작전 카드를 앞면(즉시 효과)으로 쓰거나, 뒷면(함정)으로 엎어둔다
■ 밤에 벌어지는 일 (동시 공개)
   - 그날의 전장(한국의 거리 하나)이 공개된다
   - 양쪽이 몰래 정한 출동조(최대 2명)가 동시에 공개된다
   - 함정 발동 → 능력 발동 → 파워 합 비교 → 이긴 쪽이 코어 1개
■ 딱 하나의 페널티: 출동한 캐릭터는 다음 하루 동안 "피로" (출동·능력 불가)
```

숫자 계산은 "파워 더하기"뿐이다. 에너지도, 코스트도, 공격 대상 지정도 없다.

## 1. 왜 이 구조인가 (설계 근거)

| 문제 (기존 카드게임) | v2의 답 |
|---|---|
| 마나 커브 계산이 진입장벽 | 자원 시스템 삭제. 하루 2장, 그게 전부 |
| 내 턴에만 게임하고 상대 턴은 구경 | 동시 비밀 준비 + 동시 공개 → 모든 순간이 내 턴 |
| 필드가 쌓이면 계산량 폭발 | 전투는 밤마다 1회, 출동자 최대 2:2로 고정 |
| 강한 카드를 매턴 우려먹음 | 피로 시스템 — 에이스를 쓴 다음 날이 약점이 된다 |
| 긴 게임, 역전 불가 | 코어 3선취(보통 5~7일 = 5~7라운드), 진 쪽 보급 보너스 |

심리전의 뼈대는 **"상대가 아는 것"의 설계**다:
상대는 내가 낮에 몇 장을 엎었는지(매수)는 보지만 내용은 모른다.
누가 피로인지는 서로 공개다. 그래서 "쟤네 에이스는 오늘 못 나온다,
그럼 이 밤은 내가 약한 조로 이기고 코어를 훔친다" 같은 수읽기가 생긴다.

## 2. 게임 준비

- 덱 **16장** = 캐릭터 6장 + 작전 10장 (같은 캐릭터 1장, 같은 작전 2장까지)
- 전장 덱: 공용 지역 카드 8장을 섞어 두고 매일 밤 1장 공개
- 시작 손패 5장, 코어 트랙 0:0에서 시작
- 필드 구성 (각자):

```
[ 대기조 ]  낮에 올려둔 캐릭터들 (공개, 인원 제한 없음)
[ 피로석 ]  어젯밤 출동한 캐릭터 (공개, 오늘 하루 사용 불가)
[ 매설칸 ×2 ]  엎어둔 작전 카드 (뒷면, 매수만 공개)
```

## 3. 하루의 흐름 (라운드 구조)

### ① 아침 — 보급
- 1드로우. **어젯밤 패배자는 2드로우** (정부 지원 — 캐치업 장치)
- 피로석의 캐릭터를 대기조로 복귀 (어젯밤 출동자가 새로 피로석으로)

### ② 낮 — 준비 (서로 비밀)
손패에서 **2장까지** 플레이한다. 할 수 있는 일 3가지:
- **캐릭터를 대기조에 올린다** — 올리는 것 자체는 공개 (전력 과시)
- **작전 카드를 앞면으로 쓴다** — 즉시 효과 발동 (전술)
- **작전 카드를 뒷면으로 엎는다** — 매설칸에 함정으로 (내용 비밀)
- 낮의 마지막에 **캐릭터 낮면 능력** 사용 가능 (대기조에서, 캐릭터당 1회)

### ③ 밤 — 균열 전투 (동시 공개)
1. 전장 덱에서 오늘의 전장 공개
2. 양쪽이 **출동조(0~2명)를 비밀리에 지정** → 동시 공개
3. 처리 순서 (이벤트 큐, 매설이 오래된 순):
   `함정 발동 → 듀오 합동기 성립 → 밤면 능력 발동 → 전장 효과 → 파워 합산`
4. 파워 합이 높은 쪽이 **코어 1개** 획득
   - 무승부(동률·양쪽 0명 포함): 코어는 이월 — **내일 밤은 코어 2개가 걸린다**
5. 출동자는 피로석으로

### ④ 자정 — 판정
- 코어 3개 도달 → 즉시 승리
- 덱이 다 떨어진 아침이 오면, 그 시점 코어가 많은 쪽 승리 (동률이면 마지막 밤 승자)

## 4. 캐릭터 카드 — 낮면 / 밤면

한 장의 카드에 두 얼굴을 인쇄한다 (N~UR 아트가 낮면↔밤면으로 대응:
일상복 아트가 낮면, 전투 코스튬 아트가 밤면 — **수집한 아트가 곧 룰이 된다**).

| 캐릭터 | 낮면 능력 (생활인) | 밤 파워 | 밤면 능력 (대응관) |
|--------|------------------|:---:|------------------|
| 세라 | **경호 근무**: 오늘 엎은 함정 1장은 상대 효과로 공개·무효되지 않음 | 7 | **암살**: 상대 출동이 1명이면 파워 +3 |
| 유나 | **훈련**: 내일 밤 유나 파워 +3 (누적 가능) | 6 | **정직한 실력**: 이 전투에서 서로의 밤면 능력 무효, 파워로만 승부 |
| 하린 | **정보 수집**: 상대 매설칸 1장을 몰래 확인 | 5 | **마탄 룰렛**: 파워 +0~+5 무작위 (시드 난수) |
| 미소 | **구조 훈련**: 아군 1명을 피로석에서 즉시 복귀 | 5 | **홈그라운드**: 전장이 물가면 파워 2배 |
| 다인 | **집필**: 1드로우 | 4 | **우중 매복**: 이 전투에서 아군 함정이 발동할 때마다 파워 +3 |
| 솔 | **지휘**: 오늘 카드를 3장까지 플레이 가능 | 6 | **통솔**: 함께 출동한 파트너 파워 +2 |
| 리유 | **도발 방송**: 상대는 오늘 밤 반드시 1명 이상 출동해야 한다 | 5 | **솔로 캐리**: 단독 출동이면 파워 +4 |
| 채아 | **수송**: 오늘 매설칸 제한 없이 엎을 수 있음 | 8 | **설한**: 승리 시 상대 출동자 전원 이틀 피로 (빙결) — 단, 채아 자신도 반동으로 이틀 피로 |

파워 설계 기준: 총합이 비슷해도 **언제 강한가**가 다르게 (세라·리유는 상황 파워,
채아는 상시 최강이지만 회전율 최악, 유나는 능력 무효라는 가위바위보 축).

### 듀오 합동기 (같은 밤에 함께 출동하면 자동 발동)

| 듀오 | 합동기 |
|------|--------|
| 세라+하린 | 미드나잇 세션: 전투 전에 상대 매설 전부 확인 |
| 유나+리유 | 막내즈 러시: 이 밤 승리 시 내일 아침 드로우 +1 |
| 미소+채아 | 레스큐 스피릿: 패배해도 두 사람은 피로되지 않음 |
| 솔+세라 | 검의 사제: 상대 함정 전부 불발 |
| 다인+하린 | 취재 라인: 이 밤 무승부면 코어를 우리가 가져감 |
| 솔+유나 | 탄도 계산: 전장 효과 무시 |

## 5. 작전 카드 — 앞면 / 뒷면 (10종 초안)

같은 카드가 앞면(낮 전술)과 뒷면(밤 함정)의 다른 효과를 가진다.
"이 카드를 지금 쓸까, 밤을 위해 엎을까"가 매일의 고민이 된다.

| 카드 | ☀ 앞면 (낮 전술) | 🌙 뒷면 (밤 함정, 발동 조건 → 효과) |
|------|----------------|-----------------------------------|
| 연막탄 | 상대 매설 1장을 주인 손으로 되돌림 | 상대 2명 출동 → 1명 강제 귀환(파워 계산 제외) |
| 보급 요청 | 2드로우 | 아군 총파워가 밀림 → 아군 전원 +2 |
| 도청 | 상대 손패 1장 무작위 확인 | 상대 함정 발동 → 그 함정 무효 |
| 바리케이드 | 오늘 밤 무승부 시 이월 코어 2개로 | 상대 단독 출동 → 그 캐릭터 파워 -3 |
| 오버클럭 | 아군 1명 내일까지 파워 +2 | 아군 공명 캐릭터 출동 중 → +4, 전투 후 그 캐릭터 이틀 피로 |
| 응급 키트 | 아군 1명 피로 회복 | 아군 패배 확정 → 출동자 피로 면제 |
| 저격 지원 | (즉발) 상대 대기조 1명 내일 파워 -2 | 상대 파워 8 이상 존재 → 그 캐릭터 -4 |
| 언론 플레이 | 상대 다음 낮 1장만 플레이 가능 | 상대 듀오 출동 → 합동기 무효 |
| 비상 소집 | 덱에서 캐릭터 1장 서치 | 아군 0명 출동인 밤 → 손패 캐릭터 1명 긴급 출동 |
| 이중 스파이 | 상대가 오늘 엎은 카드 매수만큼 드로우 | 상대 전술(앞면) 사용 → 그 효과를 나도 복사 |

덱 구축 결과: 캐릭터 6/8 선택 × 작전 10/20(2장씩) 선택 —
"함정 중심 다인 덱", "회전율 미소 덱", "채아 원펀치 덱" 같은 아키타입이 나온다.

## 6. 판정 규칙 (엔진 계약 승계)

- **황금률**: 카드 텍스트 > 본 룰. "할 수 없다" > "할 수 있다" 유지
- **큐**: 밤 처리 순서는 3절 ③-3의 고정 순서. 같은 단계 안에서는
  매설(배치)이 오래된 순 → 코어 트랙이 뒤진 쪽 먼저
- **일괄 판정**: 파워 합산은 모든 효과 처리 후 정확히 1회만 수행
  (중간 합산 없음 — "이 시점 파워" 참조 카드는 만들지 않는다)
- **재검증**: 함정 조건의 대상이 선행 함정으로 사라지면 불발 (`rules.md` 4절)
- **난수**: 하린 룰렛 포함 전부 시드 파생 (`rules.md` 7절)
- **동시 공개 구현**: 양쪽 입력을 커밋(해시) → 공개 방식.
  비동기 PvP에서 서버 없이도 치팅 방지 가능 (커밋-리빌 방식)
- **키워드 사전**: 피로 / 이틀 피로 / 출동 / 매설 / 이월 / 무효 / 복귀 —
  `rules.md` 6절 사전에 이 7개를 등록하고 시작한다

### 판례 1호~4호

1. **리유 도발 방송 vs 상대 캐릭터 전원 피로**: 출동 가능자가 0명이면 강제
   출동은 불발. 불가능은 강제에 우선한다.
2. **유나 능력 무효 vs 듀오 합동기**: 합동기는 "능력"이 아니라 "상태" — 무효
   대상이 아니다. (유나로 합동기를 못 막는다. 막으려면 「언론 플레이」 함정)
3. **채아 설한 vs 미소·채아 듀오**: 채아의 자기 반동(이틀 피로)은 패배가 아니
   므로 레스큐 스피릿으로 면제되지 않는다.
4. **이월된 밤의 코어 2개 + 취재 라인**: 무승부 시 2개 전부 가져간다.

## 7. 첫 판 예시 (하루의 실제 플레이)

> **3일차 아침** — 코어 1:1. 나는 어제 패배해서 2드로우.
> 상대 피로석에 채아(파워 8)가 보인다. **오늘 밤 채아는 못 나온다.**
>
> **낮** — 나는 유나를 대기조에 올리고(공개), 카드 1장을 엎는다(내용 비밀).
> 유나의 낮면 「훈련」 사용: 내일 밤 유나 +3. 상대는 2장을 엎었다. 함정 둘?
>
> **밤** — 전장 공개: 「해운대」(물가). 아차, 상대 대기조에 미소가 있다 —
> 홈그라운드 2배. 나는 고민 끝에 세라 단독 출동(암살 +3 노림), 상대는
> 미소 단독 출동. 동시 공개! 상대 함정 「바리케이드」 발동 — 단독 출동한
> 세라 -3. 파워 세라 7+3-3=7 vs 미소 5×2=10. **상대가 코어 획득 (1:2).**
>
> 하지만 상대의 미소는 이제 피로. 내일 밤 훈련된 유나(6+3)가 갈 곳에
> 상대가 낼 수 있는 최고 파워는… — 이런 하루가 5~7번이면 게임이 끝난다.

## 8. 문서 지위

- 플레이 룰: **rules-v2.md(본 문서)가 유일 기준** (rules.md 1~4절의 구 플레이
  룰은 폐기, 엔진 계약 절만 존속)
- battle-design.md의 카드 풀(함정/전술/지역 아이디어)은 v2 작전·전장 카드의
  소재 창고로 유지
- 수집(P0) 연동: 등급(N~UR)은 **같은 캐릭터 카드의 아트·프레임 차등**으로 유지.
  v2에서 등급은 전투 스탯에 영향을 주지 않는다 — 밸런스는 룰이, 과시는 컬렉션이
  담당한다 (pay-to-win 원천 차단, 규제 리스크 최소화)
