# AURA — 카드 컬렉션 프로토타입

AI 실사 캐릭터 이미지를 활용한 수집형 카드 게임(TCG)의 첫 프로토타입입니다.
서버 없이 동작하는 단일 HTML 파일이며, `index.html`을 브라우저로 열면 바로 플레이할 수 있습니다.

## 현재 들어 있는 것

- **팩 상점**: 150코인으로 팩 1개(카드 5장) 개봉, R 등급 이상 1장 보장
- **개봉 연출**: 카드 뒤집기(3D 플립), 신규 카드 NEW 뱃지, SR/UR 글로우 효과
- **등급 시스템**: N(60%) / R(28%) / SR(10%) / UR(2%)
- **중복 보상**: 이미 가진 카드가 나오면 등급별 코인으로 자동 전환 (N 10 / R 30 / SR 100 / UR 300)
- **도감**: 캐릭터 8명 × 등급 4종 = 32장, 수집률 표시, 카드 확대 보기
- **재화 루프**: 무료 코인 버튼(60초 쿨다운, +80), 진행 상황은 브라우저 localStorage에 저장

## AI 실사 이미지 넣는 법

지금 카드 아트는 자리표시(캐릭터별 색상 + 모노그램)입니다.
이미지가 준비되면 `index.html`의 `CARD_IMAGES`에 카드 ID → 이미지 경로만 추가하면 됩니다.

```js
const CARD_IMAGES = {
  'sera-N':  'images/sera-n.jpg',
  'sera-UR': 'images/sera-ur.jpg',
  // 카드 ID 형식: <캐릭터id>-<등급>  (캐릭터 id는 CHARACTERS 배열 참고)
};
```

카드 비율은 5:7이므로 이미지도 세로형(예: 1000×1400)으로 준비하는 것이 좋습니다.
같은 캐릭터의 등급별 카드는 같은 얼굴이어야 하므로, 생성 시 LoRA나 레퍼런스 고정(IP-Adapter 등)으로 얼굴 일관성을 잡아야 합니다.
