# AURA — 게임 기획서 v1 (수집 → 배틀 TCG 확장)

한 줄 컨셉: **"현실 한국의 거리에서 벌어지는 대응관들의 카드 배틀"**
— 수집형 카드 게임으로 시작해, 같은 카드 풀 위에 구역 점령형 배틀 TCG를 얹는다.

---

## 1. 단계별 로드맵

| 단계 | 이름 | 내용 | 상태 |
|------|------|------|------|
| P0 | 수집 코어 | 팩 개봉 + 도감 + 재화 루프 | **완료 (현 프로토타입)** |
| P1 | 아트 교체 | AI 실사 카드 이미지 40장(N라인 시트 → 등급 코스튬) 적용 | 진행 예정 |
| P2 | 카드 스탯 | 카드에 코스트/파워/스킬 데이터 부여, 카드 상세 화면 | |
| P3 | PvE 배틀 | "균열 소탕전" — AI 상대 구역 점령전, 스테이지 보상 | |
| P4 | 덱 빌딩 | 덱 편집기, 캐릭터 중복 제한, 덱 저장 | |
| P5 | 비동기 PvP | 상대 덱(고스트)과 대전, 랭킹 시즌 | |
| P6 | 시즌 2 | 신규 캐릭터 4인(힐러/서포터), 신규 구역, 픽업 팩 | |

원칙: **각 단계는 이전 단계의 데이터를 버리지 않는다.**
P0에서 모은 카드가 P3에서 그대로 전투 카드가 되어야 수집이 헛되지 않다.

---

## 2. 전투 시스템 코어 (P3~P5)

### 형식: 6턴 · 3구역 점령전

모바일 세로 화면, 한 판 3~5분을 목표로 한 구역 점령형(location battler) 룰.

- 필드에 **구역 3곳**이 공개된다 (턴 1·2·3에 하나씩 오픈)
- 매 턴 **에너지**가 1씩 증가 (턴 1 = 1에너지 … 턴 6 = 6에너지)
- 에너지로 손패의 카드를 구역에 배치, 구역당 최대 4장
- 6턴 종료 시 **구역별 파워 합**을 비교, 2개 구역 이상 이기면 승리
- 무승부 구역은 전체 파워 합산으로 판정

짧고, 서버 없이 PvE부터 구현 가능하고, 카드 수가 적어도(32장) 성립하는 룰이라
1인 개발 확장에 가장 현실적이다.

### 구역 = 실제 한국 로케이션

세계관의 "균열 발생지"를 구역으로 쓴다. 구역마다 고유 효과가 있다.

| 구역 | 효과 예시 | 연고 캐릭터 |
|------|----------|------------|
| 강남 대로 | 밤 턴(4턴 이후) 배치 카드 +2 | 세라 |
| 대학 캠퍼스 | 코스트 2 이하 카드 +1 | 유나 |
| 을지로 재즈 바 | 배치 시 카드 1장 드로우 | 하린 |
| 해운대 | 물 태그 카드 파워 2배 | 미소 |
| 빗속 골목 | 여기 배치된 카드는 스킬 피해 무효 | 다인 |
| 북촌 한옥마을 | 아군 전체 +1 | 솔 |
| 네온 스트리트 | 카드를 2장 이상 배치한 턴 +3 | 리유 |
| 설악산 능선 | 코스트 5 이상 카드만 배치 가능, +4 | 채아 |

**연고지 보너스**: 캐릭터가 자기 연고 구역에 배치되면 추가 효과 발동.
"우리 동네에서 싸우면 강하다"는 직관적이고 한국 배경 정체성을 강화한다.

### 태그 시스템

설정집의 무장 이원화를 그대로 태그로 쓴다.

- **공명(共鳴)** 태그: 판타지 무장 계열 스킬 — 화려한 단발 효과
- **화기(火器)** 태그: 현대 무기 계열 스킬 — 견실한 지속/제거 효과
- 보조 태그: 근접 / 원거리 / 물 / 빙결 / 지휘 등

시너지 예: "공명 카드가 3장 이상이면…", "화기 카드 배치 시 상대 카드 -1" 등.
같은 캐릭터라도 등급에 따라 태그 비중이 달라져 덱 색깔이 갈린다.

## 3. 카드 스탯 설계

### 등급 → 전투 역할 매핑

수집 등급이 곧 전투에서의 "같은 캐릭터의 다른 버전"이다.

| 등급 | 코스트 대역 | 설계 방향 |
|------|-----------|----------|
| N (일상복) | 1~2 | 바닐라~저코스트 유틸. 스킬 없거나 단순 |
| R (제복) | 2~3 | 화기 태그 중심, 견실한 효율 |
| SR (전투) | 3~5 | 공명 태그 발현, 구역/시너지 스킬 |
| UR (각성) | 5~6 | 판을 뒤집는 피니셔 |

### 덱 규칙

- 덱은 **12장**, **같은 캐릭터는 1장만** (등급 중 하나를 선택)
- → "세라를 N으로 넣어 저코스트를 챙길까, UR로 넣어 피니셔로 쓸까"가
  덱 빌딩의 핵심 고민이 된다. 32장 풀에서도 조합 수가 충분히 나온다.

### 캐릭터별 고유 스킬 초안 (UR 기준)

| 캐릭터 | UR 스킬 | 설정 근거 |
|--------|---------|----------|
| 세라 | 배치 시 이 구역 상대 최고 파워 카드 1장 무력화 | 어둠 속 일격 (야상곡) |
| 유나 | 다른 구역에 있는 상대 카드 1장에 -3 | 곡사 화살 (개양) |
| 하린 | 배치 시 무작위 속성 효과 1개 발동 (6종 룰렛) | 6속성 마탄 (스캣) |
| 미소 | 물 태그 부여, 이 구역이 해안이면 파워 2배 | 해류 조종 (물마루) |
| 다인 | 이 구역 아군은 상대 스킬 대상이 되지 않음 | 우산 방패 (장마) |
| 솔 | 배치 시 모든 아군 +1, 지휘 태그당 추가 +1 | 현장 지휘관 (인왕) |
| 리유 | 이 턴에 낸 카드 수 × +2 | 히트앤런 연타 (핑퐁) |
| 채아 | 배치 시 이 구역 상대 전원 빙결(다음 턴 스킬 봉인) | 빙결 도끼 (설한) |

밸런스 기준: 바닐라 스탯 대비 스킬 가치 = 코스트 1당 파워 2 환산으로 시작해
PvE 플레이 데이터로 조정한다.

## 4. 수집 ↔ 배틀 경제 연동

### 재화 흐름 (P3 이후)

```
팩 개봉 ─→ 신규 카드 ─→ 덱 강화
   ↑            └→ 중복 카드 ─→ 코인(현행) + 각성 조각(신규)
   └───── 코인 ←──── PvE 스테이지 보상 / 일일 임무
```

- **중복 보상 확장**: 현행 "중복 = 코인"에 **각성 조각**을 추가.
  같은 카드 중복 3장 = 카드 레벨 +1 (파워 +1, 최대 3레벨).
  수집만 하던 유저의 중복이 전투 성장 재료로 자연 전환된다.
- **PvE 보상**: 스테이지 클리어 시 코인 + 첫 클리어 보너스로 지정 카드 지급
  (초반 덱 구성이 뽑기 운에 좌우되지 않도록 안전장치)

### 유료화 원칙 (실서비스 전환 시)

- 1차: 무료 + 광고 없음으로 검증 → 2차: 팩 직접 구매(확정 재화)부터 도입
- 확률형(가챠) 도입 시: 게임산업법상 **확률 공시 의무** 대응 필요,
  천장(피티) 시스템 — 팩 40개당 UR 1장 확정 — 을 처음부터 설계에 포함
- 전 연령 등급 유지: 카드 아트는 전신 일상복/전투복 기준, 노출 컨셉 배제

## 5. 모드 구성

| 모드 | 단계 | 설명 |
|------|------|------|
| 균열 소탕전 (PvE) | P3 | 스테이지식 캠페인. 지역별 챕터(강남→해운대→설악산), 보스는 대형 이형 |
| 일일 임무 | P3 | "팩 1회 개봉", "공명 카드 5장 배치" 등 코인 수급처 |
| 고스트 대전 (PvP) | P5 | 상대 유저의 덱을 AI가 조작하는 비동기 대전. 실시간 서버 불필요 |
| 랭킹 시즌 | P5 | 월간 시즌, 등급 보상으로 시즌 한정 카드 프레임 |

PvE 캠페인의 챕터 구조는 캐릭터 연고지 순회로 짠다. 각 챕터 클리어 시
해당 지역 연고 캐릭터의 스토리 컷(카드 아트 재활용)을 보여줘
수집-스토리-전투가 하나로 묶이게 한다.

## 6. 기술 확장 계획

현 프로토타입(단일 HTML + localStorage)에서 단계별로 확장한다.

- **P2**: `CARDS` 배열에 `cost / power / tags / skill` 필드 추가.
  카드 상세 모달에 스탯 표기. 저장 스키마 버전을 `aura-tcg-v2`로 마이그레이션
- **P3**: 배틀 씬을 별도 모듈(`battle.js`)로 분리. 상태머신
  (드로우→배치→구역판정) + 스킬을 이벤트 훅(onReveal/onTurnEnd)으로 구현.
  AI는 "남는 에너지 최소화 + 이기는 구역 우선" 휴리스틱이면 초기엔 충분
- **P4**: 덱 데이터는 카드 ID 12개 배열로 localStorage 저장
- **P5**: 이 시점에만 백엔드 필요 (계정, 덱 업로드, 랭킹).
  Supabase/Firebase급이면 충분. 확률 로그 서버 기록도 이때 도입
- 이미지: 등급 코스튬 40장 + 구역 배경 8장 + 보스 이형 아트가 P3까지의 발주량

## 7. 시즌 2 훅 (P6)

- 신규 캐릭터 4인: 설정집 밸런스 표에서 비워둔 **힐러/서포터 + 30대 중반 이상**
  연령대를 채운다 (예: 군의관 출신 응급의학과 의사, 국악인, 형사, 셰프)
- 신규 메커니즘: "증원" (턴 중 손패로 캐릭터를 잠깐 불러오는 지원 카드)
- 신규 구역 4곳 + 기존 구역 리메이크
- 콜라보 여지: 실사 IP 특성상 배우/모델과 정식 초상권 계약을 맺고
  "실존 인물 콜라보 카드"를 내는 것이 장기 차별화 포인트 (반드시 계약 기반)
