# 10_03 AI Photoreal Pipeline

AI 생성 실사 아트(D-023)의 제작 파이프라인 정본. 생성 도구는 GPT(이미지 생성)·Grok 계열을 사용하며, 도구가 바뀌어도 본 문서의 절차·규격은 유지된다.

## 1. 파이프라인 개요

```
콘티(텍스트) → 프롬프트 조립(§3) → AI 생성(N안) → 선별 → 후처리(10_01 §3) → 명명·등록(10_01 §5) → 일관성 QA(§6)
```

- 생성은 **장면(scene) 단위**로 한다. 이벤트 1종 = 씬 2~3컷 = 생성 이미지 2~3장.
- 모든 원판·선별본·최종본은 `assets/raw/`, `assets/selected/`, `assets/final/`로 분리 보관한다(원판 폐기 금지 — 재후처리 대비).

## 2. 캐릭터 일관성 규칙 (최우선 난제)

AI 실사의 최대 리스크는 **컷마다 다른 사람이 되는 것**이다. 아래를 강제한다.

| 규칙 | 내용 |
|---|---|
| 캐릭터 시트 선행 | 본편 생성 전에 엄마 1인·아이 5연령(`age0/1/3/5/6`)·주요 NPC의 **레퍼런스 시트**(정면·측면·전신, 동일 인물 3컷 이상)를 먼저 확정한다. 이 시트가 인물의 정본이다 |
| 레퍼런스 재투입 | 모든 인물 컷은 텍스트 프롬프트만으로 생성하지 않는다 — 확정 시트를 **이미지 레퍼런스로 첨부**해 생성한다(도구의 이미지 참조/편집 기능 사용) |
| 인물 묘사 고정문 | 프롬프트 북(§3)에 인물별 고정 묘사문(연령, 체형, 머리, 옷 세트)을 두고 복붙만 허용. 컷마다 새로 쓰지 않는다 |
| 의상 세트 | 챕터당 엄마 2세트·아이 2세트로 제한(10_02 연동). 옷이 바뀌면 다른 사람으로 보인다 |
| 얼굴 노출 최소화 문법 | 10_01 §1의 연출 문법(뒷모습·손·어깨 너머)을 기본값으로 — 일관성 부담을 구조적으로 줄이는 장치다. 정면 얼굴 컷은 챕터당 3컷 이내의 "감정 정점"에만 허용 |
| 아이 성장 연속성 | 연령 시트 5종은 동일 인물의 성장으로 보여야 한다. 시트 확정 시 5연령을 한 화면에 나열해 검수 |

## 3. 프롬프트 북 (prompt book)

`assets/prompt_book.md`에 아래 블록을 관리한다. 장면 프롬프트는 블록 조립으로만 만든다.

```
[장면 프롬프트 = 카메라 + 인물(고정문+레퍼런스) + 장소 + 시간블록 라이팅 + 소품 + 공통 스타일 + 금지]
```

| 블록 | 예시 |
|---|---|
| 공통 스타일 | "한국 다큐멘터리 사진, 자연광, 저채도, 생활감, 세로 구도 3:4 이상" |
| 카메라 | 컷 유형별 고정: 일상 컷 = 50mm 눈높이 / 감정 컷 = 85mm 어깨 너머 / 공간 컷 = 28mm |
| 장소 | 06_02 location별 고정 묘사문 (예: loc_home_living = "한국 24평 구축 아파트 거실, 15년 된 마루, 빨래 건조대") |
| 라이팅 | 10_01 §4 표의 time_block별 색온도·광원 서술을 문장화해 고정 |
| 금지(네거티브) | "화보 느낌, 과도한 보정, 서양식 주택 내부, 연예인 얼굴, 브랜드 로고, 텍스트·워터마크" |

- 프롬프트 북의 고정문 변경은 아트 캐논 변경이다 — DECISION_LOG 등재 후에만 허용.
- **한국 정합 체크(Pillar 3·D-019)**: 생성물에서 서구식 인테리어·비한국식 소품(신발 신은 실내 등)이 나오면 무조건 리테이크. 검증 질문 — "이 사진을 한국 부모가 보고 '우리 집 같다'고 하는가?"

## 4. 컷 유형과 생성 우선순위

| 유형 | 수량(수직 슬라이스 기준) | 비고 |
|---|---|---|
| 공간 컷 (배경) | loc_home_living·bedroom × time_block 5 = 약 8~10장 | 인물 없음 — 일관성 부담 없어 최우선 생산 |
| 일상 컷 (인물+공간) | 슬라이스 4일 × 2~3컷 = 약 10장 | 뒷모습·손 위주 |
| 감정 정점 컷 | 첫 미소 1~2장 | 유일하게 아기 정면 허용. 최다 리테이크 예산 배정 |

## 5. 법무·스토어 체크리스트 (출시 전 필수)

| 항목 | 내용 | 상태 |
|---|---|---|
| 상업적 이용 권리 | 사용한 생성 도구(GPT·Grok)의 약관에서 산출물의 상업적 이용·소유권 조항 확인 및 근거 보관 | 미확인 — 착수 전 확인 필수 |
| 스토어 고지 | Steam은 AI 생성 콘텐츠 고지 의무. App Store·Play Store 정책도 출시 시점 기준 재확인 | 예정 |
| 초상권 | 실존 인물 유사 얼굴 금지(§3 네거티브). 감정 정점 컷은 유사도 육안 검수 | 규칙 반영됨 |
| 원판 보존 | 생성 일시·도구·프롬프트를 에셋별 메타(`assets/final/*.meta.json`)로 기록 — 권리 입증·재생성 대비 | 규격 확정 |

## 6. 일관성 QA (15_QA 연동)

| check_id | 검사 | 통과 기준 |

## 7. 기존 문서와의 관계

- **10_01**: 팔레트·라이팅·명명 규칙은 그대로 유효 — 붓 규격만 후처리 규격으로 대체됨.
- **10_02**: 캐릭터의 연령 단계·자세 변화·실루엣 의도는 유효. "그리는 방법"이 "생성·선별하는 방법"으로 바뀌었을 뿐, "무엇을 보여줄 것인가"는 동일.
- **수채 목업**(`mockup_ingame_sample.html`): UI 레이아웃·문장형 표기의 레퍼런스로 유지. 장면 아트 스타일 레퍼런스로는 더 이상 사용하지 않음.
