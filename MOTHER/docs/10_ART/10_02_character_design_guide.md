# 10_02 Character Design Guide

10_01의 화풍(절제된 수채·과슈, 과장 없는 인체 비례)을 전제로 캐릭터 규격을 정의한다. 수치 상태는 숫자가 아닌 외형·자세로 번역한다(Pillar 1, D-004).

## 1. 엄마 (`player`) 디자인

- 기본 비례: 성인 실사 비례 7등신. 30대 초반. 얼굴은 특정 배우형이 아닌 보편형(플레이어 자기 투영 허용).
- 챕터별 변화는 "시간의 경과 + 피로의 누적과 회복"을 옷·머리·자세로 보여준다. 극적 노화 표현 금지(7년 경과).

| 챕터 | 머리 길이 | 기본 복장 | 피로 표현 기본값 |
|---|---|---|---|
| CH1 | 어깨 아래 긴 머리 → 산후 대충 묶은 낮은 포니테일 | 수유복·무릎 나온 트레이닝복, 카디건 | 눈 밑 음영 상시, 어깨 전방 굴곡 5° |
| CH2 | 단발로 자름(첫 자기 결정 연출) | 이지웨어 + 얼룩 방지 앞치마, 복직 후 midday·afternoon 한정 오피스 셋업 | 음영 유지, 손목 보호대 소품 |
| CH3 | 단발 유지, 정돈됨 | 캐주얼(등원룩), 주말 야외복 | 음영 완화, 자세 직립 회복 |
| CH4 | 어깨선까지 자람, 반묶음 | 시즌 아우터 추가(가을·겨울 톤, 10_01 `pal_ch4_dusk` 연동) | 표정 위주(§4), 자세는 정상 |
| CH5 | 반묶음 + 입학식 날만 풀 세팅 | 입학식 정장(밝은 베이지, `#FFF6E8` 계열) | 피로 표현 제거, 눈가 옅은 주름 1선만 잔류 |

- mind 밴드 연동 포즈 세트(03_01): `stable` = 기본 세트 / `strained` = 어깨 굴곡 +5°, 느린 idle / `depleted` = 앉은 자세 idle, 시선 하향. 파일명 예: `spr_player_strained_idle`.

## 2. 아이 (`child`) 연령별 디자인 5단계

스프라이트 접미 `age0`~`age6`(10_01 §4). 헤드 비율(등신)은 실측 아동 비례 기준으로 하고 데포르메하지 않는다(Pillar 2).

| 단계 | 시기(챕터) | 헤드 비율 | 신체·동작 특징 |
|---|---|---|---|
| `age0` | 0~12개월 (CH1) | 3.8등신 | 목 가누기→배밀이→잡고 서기. 항상 안기거나 누운 포즈 중심 |
| `age1` | 1~3세 (CH2) | 4.2등신 | 뒤뚱 걷기, 배 내민 직립. 손은 항상 무언가 쥐고 있음 |
| `age3` | 3~5세 (CH3) | 4.8등신 | 달리기·점프 가능. 유치원 원복 소품 추가 |
| `age5` | 5~6세 (CH4) | 5.4등신 | 팔다리 길어짐, 성별 중립 캐주얼. 표정 연기 범위 최대 |
| `age6` | 6~7세 (CH5) | 5.8등신 | 초등 입학 체형. 책가방(노란 커버) 소품, 걸음이 엄마 보폭에 근접 |

## 3. 성격 축 → 외형·자세 번역 규칙 (D-008)

성격 축 4종(0~100)은 숫자 노출 금지. 구간(저: 0~39 / 중: 40~69 / 고: 70~100)별로 idle·리액션 포즈를 교체한다. 03_01의 `distant`/`secure` 행동 세트(attachment 기준)와 중첩 적용된다.

| 축 | 저구간 (0~39) | 고구간 (70~100) |
|---|---|---|
| `confidence` | 웅크린 어깨, 턱 당김, 새 활동 앞에서 엄마 뒤로 반보 후퇴 | 가슴 편 직립, 손 들기·앞장서기 포즈 |
| `empathy` | 타인 우는 장면에서 시선 회피 idle | 다가가 어깨에 손 얹는 리액션 스프라이트 사용 |
| `independence` | 엄마 옷자락 쥔 손 상시 표시(`spr_child_age*_cling`) | 혼자 신발 신기·가방 메기 등 단독 동작 세트 |
| `expressiveness` | 표정 변화 폭 축소(세트 중 미세 표정만 사용), 몸짓 작음 | 팔 전체를 쓰는 큰 제스처, 표정 세트 전 범위 사용 |

- 중구간은 기본 세트. 구간 판정은 03_01 밴드 규칙(블록 종료 시점 1회)을 따른다.
- 두 축이 충돌하면 장면의 `emotion_tags`와 관련 깊은 축을 우선한다(예: `comparison` 장면은 confidence 우선).

## 4. 표정 세트 규격

| 대상 | 세트 수 | 구성 |
|---|---|---|
| 엄마 | 3단계 세트 (mind 밴드 연동) | `stable` 8종 / `strained` 8종 / `depleted` 6종. 각 세트: 중립, 미소, 웃음, 걱정, 슬픔, 분노 억제, 피로, (stable·strained만) 놀람 |
| 아이 `age0` | 1세트 6종 | 수면, 울음 3단(칭얼→울음→발작적 울음, 11_01 울음 설계와 파일명 공유), 옹알이, 웃음 |
| 아이 `age1` | 1세트 8종 | 위 6종 + 고집(도리질), 호기심 |
| 아이 `age3` | 1세트 10종 | + 자랑, 시무룩 |
| 아이 `age5` | 1세트 12종 | + 서운함(참는 표정), 화해 후 겸연쩍음 |
| 아이 `age6` | 1세트 12종 | age5 세트 재사용 + 입학식 전용 2종(설렘, 뒤돌아보는 미소) 교체 |

- 파일명: `spr_{entity}_{set}_{expression}` 예: `spr_player_depleted_smile`, `spr_child_age3_proud`.
- "엄마는 슬펐다"식 직접 서술 금지(01_04 §3) — 슬픔 표정도 눈물 대신 시선·입매로 표현하는 것을 기본으로 한다.

## 5. NPC 실루엣 구분 규칙

NPC는 얼굴 디테일을 줄이고 실루엣으로 역할을 즉시 식별하게 한다(주연은 엄마·아이 2인뿐임을 시각적으로 강제).

| NPC | 식별자 | 실루엣 키 |
|---|---|---|
| 남편 | `npc_husband` | 세로로 긴 직선 실루엣, 정장/출근 가방. 등장 빈도 낮음을 전제 |
| 친정 엄마 | `npc_grandma` | 둥근 어깨선, 꽃무늬 상의, 보자기 소품 |
| 조리원 동기·이웃 | `npc_peer` | 유모차·아기띠 소품으로만 구분, 얼굴 명도 배경에 근접 |
| 어린이집·유치원 교사 | `npc_teacher` | 앞치마 + 명찰, 상반신 위주 등장 |
| 비교 대상 타인(`comparison` 장면) | `npc_other` | 채도 0에 가까운 회색 `#9AA0A8` 단색 실루엣(10_01 CH3 보조색) |

- 규칙: 모든 NPC는 3m 거리 축소 스케일에서 실루엣만으로 구분 가능해야 한다(QA-10 계열에서 검증, 15_02).
- NPC 표정 세트는 1세트 4종(중립, 미소, 곤란, 걱정)으로 고정. 주연보다 감정 해상도를 낮게 유지한다.
