# 08_02 Writing Guidelines

가이드 문서. 모든 `text_kr` 작성의 단일 기준이며, 08_01의 콘텐츠 린트와 15_QA 리뷰가 본 문서를 근거로 리젝한다. 감정 전달 우선순위(01_04 §2)에서 대사는 3순위 수단이다 — 행동과 연출로 보여줄 수 있으면 대사를 쓰지 않는다.

## 1. 절제 원칙 — 설명하지 말고 보여주기

1. **대사는 마지막 수단이다.** 아이의 행동 변화(1순위)·일상의 변주(2순위)로 전달 가능한 정보를 대사로 반복하지 않는다.
2. **감정은 이름 붙이지 않는다.** "슬퍼", "행복해", "미안해서 그래" 같은 감정 명명 대신, 감정이 새어 나오는 행동·말버릇을 쓴다. "엄마는 슬펐다"식 서술은 전면 금지(01_04 §3).
3. **정보의 절반만 말한다.** 인물은 자기 상황을 요약해 주지 않는다. 플레이어가 문맥으로 조립하게 남긴다.
4. **현실의 말투를 쓴다(Pillar 2·3).** 번역투·연극조 금지. 한국의 실제 육아 대화(맘카페 어휘, 조리원 동기 존댓말 등)를 기준으로 한다.

## 2. 문장 길이 상한

| 대상 | 상한 | 비고 |
|---|---|---|
| 대사 `text_kr` | **40자** (공백 포함) | 08_01 린트 기준. 말풍선 1~2줄 보장 |
| 지문(연출 지시 텍스트) | 60자 | 화면 미출력, 연출팀 전달용 |
| 한 line의 문장 수 | 2문장 | 3문장 이상이면 line을 분할한다 |

- 40자를 넘는 말은 대부분 "설명"이다. 줄이지 말고 지울 것을 먼저 검토한다.

## 3. 침묵("…")의 사용 규칙

| 규칙 | 내용 |
|---|---|
| 표기 | 말줄임표는 `…` 1개만. `...`, `……` 금지 |
| 단독 침묵 | `text_kr: "…"` 단독 line 허용. 단 scene당 1회 이하 |
| 위치 | 문두 `…`는 망설임, 문미 `…`는 삼킴. 문중 사용 금지 |
| 남용 방지 | 연속 2개 line에 `…` 사용 금지. 침묵은 아껴야 침묵이다 |
| 대체 | 침묵보다 행동이 가능하면 행동으로: "(대답 대신 아이의 이불을 끌어올린다)" |

## 4. 좋은 예 / 나쁜 예 대비표

| # | 나쁜 예 | 좋은 예 | 위반 규칙 |
|---|---|---|---|
| 1 | "엄마는 너무 슬프고 지쳤다" (지문) | (지문) 개던 빨래 위에 손이 한참 머문다 | 감정 직접 서술 금지 |
| 2 | "요즘 어린이집에서 힘든 일 있어서 걱정돼" | "…오늘 가방이 왜 이렇게 무겁네." | 설명 대사, 정보 전량 발화 |
| 3 | "역시 아이한테는 사랑이 제일 중요한 거야" | "…" (아이를 다시 안는다) | 교훈적 마무리 금지 |
| 4 | "여보, 나 오늘 회사에서 육아휴직 얘기 꺼냈는데 부장님이 눈치를 줘서 너무 속상했어" (49자) | "여보. …나 오늘 부장님한테 얘기 꺼냈어." | 40자 상한, 삼킴 |
| 5 | "우리 아기 천재인가 봐!! 벌써 걷다니!!" | "…방금. 방금 봤어?" | 과장 감탄, 느낌표 남발 |
| 6 | "……미안해……" | "미안해. …밥 먹자." | `…` 표기·남용, 일상으로의 복귀 |

## 5. 호칭 규칙 (한국 가족 호칭)

| 화자 → 청자 | 호칭 | 예시 |
|---|---|---|
| `player` → 남편(`npc_husband`) | "여보" (다툼 장면에서는 이름 호칭 허용) | "여보, 애 좀 봐 줘." |
| `player` → 시어머니(`npc_mother_in_law`) | "어머니" (항상 존댓말) | "어머니, 저 이번 주는 어려워요." |
| `player` → 친정엄마(`npc_grandma`) | "엄마" (반말 허용) | "엄마, 나 진짜 모르겠어." |
| `player` → 아이(`child`) | 이름+아/야 | "지우야, 이리 와." |
| `child` → `player` | "엄마" (CH2 이후. CH1은 `vocal_tag`, 08_03) | "엄마, 물." |
| 이웃·조리원 동기 → `player` | "○○ 엄마" (아이 이름 기반 관행) | "지우 엄마, 이거 써 봤어요?" |
| 어린이집 교사 → `player` | "어머님" (존댓말) | "어머님, 잠깐 통화 가능하세요?" |

- 아이 이름은 세이브 변수 `child_name`으로 치환한다: `text_kr`에 `{child_name}` 플레이스홀더 사용.

## 6. 챕터별 문체 톤 노트 (01_04 감정 목표 연동)

| 챕터 | 엄마 대사의 톤 | 작법 포인트 |
|---|---|---|
| CH1 | 짧고 끊김. 혼잣말 비중 높음 | 대화 상대가 없는 고립(isolation)을 문장 길이로 표현 |
| CH2 | 조금 길어지고 리듬 생김 | 첫 보람(reward)의 장면에서만 감탄 1회 허용 |
| CH3 | 비교 어휘가 스민다 | "○○네는"류 표현은 타인 대사로만, 엄마 속마음 서술 금지 |
| CH4 | 말이 줄고 침묵이 는다 | `…` 사용 빈도 상향 허용(단 §3 규칙 내) |
| CH5 | 담담하고 완결된 문장 | 이별을 말하지 않으면서 이별을 준비하는 문장 |

## 7. 금지 사항

1. 감정 직접 서술("엄마는 슬펐다", "가슴이 미어졌다") — 지문·대사 모두 금지(01_04 §3).
2. 교훈적 마무리 — 장면 끝에 의미를 요약·설파하는 대사 금지. 장면은 행동으로 끝낸다.
3. 수치 언급 — 대사에서 게임 수치를 직·간접 인용 금지("애착도가 떨어진 것 같아" 류).
4. 느낌표 2개 이상, 물결표(~), 이모티콘 표기 금지.
5. 판타지·비현실 어휘 금지(Pillar 2). 시대에 맞지 않는 유행어는 15_QA 어휘 검수 대상.
6. 아이를 악역화하거나 훈계 대상으로만 쓰는 대사 금지 — 아이는 관찰되는 존재다.

## 8. 리뷰 체크리스트 (15_QA 연동)

| 항목 | 통과 기준 |
|---|---|
| 길이 | `text_kr` ≤ 40자, line당 ≤ 2문장 |
| 침묵 | scene당 단독 `…` ≤ 1, 연속 line `…` 없음 |
| 감정 명명 | 감정 형용사 직접 서술 0건 |
| 호칭 | §5 표와 불일치 0건, `{child_name}` 치환 확인 |
| 마무리 | scene 마지막 line이 교훈·요약이 아닐 것 |
