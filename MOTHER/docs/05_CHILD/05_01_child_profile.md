# 05_01 Child Profile

아이(`child`)의 생성 옵션과 기질 시드(`temperament_seed`)를 정의하는 프로필 문서다. 표 중심 구성이며, 스탯·성격 축의 동작은 05_03, 발달 단계는 05_02에서 정의한다.

## 1. 캐릭터 생성 옵션

| 항목 | 식별자 | 규칙 |
|---|---|---|
| 성별 | `child_gender` | `female` / `male` 선택. 스탯·이벤트 로직에 영향 없음. 대사 호칭·일부 연출 에셋만 분기 |
| 이름 | `child_name` | 한글 1~5자 커스텀 입력. 기본 제안값: `female` "이한별" / `male` "이도윤". 금칙어 필터 적용 |
| 기질 시드 | `temperament_seed` | `sensitive` / `easygoing` / `active` 3종 중 선택. 게임 시작 후 변경 불가 |

- 기질 선택 화면은 수치를 보여주지 않고(D-004) 신생아 묘사 문장("작은 소리에도 자주 깨는 아이였다" 등)으로 제시한다.

## 2. 기질 시드 3종 — 개요

| `temperament_seed` | 한국어 | 묘사 | 플레이 결 |
|---|---|---|---|
| `sensitive` | 예민한 기질 | 자극에 민감, 잘 깨고 잘 울지만 정서 반응이 깊다 | 고난도. 돌봄 비용↑, 애착 보상↑ |
| `easygoing` | 순한 기질 | 잘 먹고 잘 자며 낯선 상황에 무던하다 | 저난도. 변동 폭이 작고 안정적 |
| `active` | 활발한 기질 | 에너지가 넘치고 몸으로 세상을 탐색한다 | 중난도. 사고·외출 계열 이벤트 중심 |

## 3. 기질은 선천 요소다 (성격 축과의 관계)

- `temperament_seed`는 **생성 시 고정되는 선천 요소**로, D-008의 후천적 성격 축 4종(`confidence`, `empathy`, `independence`, `expressiveness`)과 완전히 별개다.
- 기질은 성격 축의 초기값(전 축 50)·변화 규칙을 바꾸지 않는다. 기질이 바꾸는 것은 **이벤트 발생 확률과 수치 반응의 보정 계수**뿐이다.
- 서사 원칙: 기질은 "고쳐야 할 문제"로 묘사하지 않는다(D-002, Pillar 2). 예민함은 결함이 아니라 아이의 결이다.

## 4. 기질별 이벤트 확률 보정

random 트리거(D-010) 이벤트의 가중치에 곱해지는 계수. scheduled 이벤트에는 적용하지 않는다.

| 이벤트 계열 (07_EVENT 카테고리) | `sensitive` | `easygoing` | `active` |
|---|---|---|---|
| 밤 울음·잠 투정 (`night_crying`) | ×1.4 | ×0.7 | ×1.0 |
| 낯가림·분리 불안 (`stranger_anxiety`) | ×1.3 | ×0.8 | ×0.9 |
| 잔병치레 (`minor_illness`) | ×1.2 | ×0.9 | ×1.0 |
| 안전사고·다침 (`accident`) | ×0.9 | ×0.8 | ×1.4 |
| 바깥 탐색·활동 제안 (`exploration`) | ×0.8 | ×1.0 | ×1.3 |
| 깊은 교감 순간 (`bonding_moment`) | ×1.2 | ×1.0 | ×0.9 |

## 5. 기질별 수치 반응 보정

선택 `effects`·행동 효과가 적용될 때 곱해지는 계수 (곱한 후 반올림, 성격 축 ±3 상한은 보정 후에도 유지).

| 반응 항목 | `sensitive` | `easygoing` | `active` |
|---|---|---|---|
| `child_condition` 감소량 | ×1.25 | ×0.85 | ×1.0 |
| `child_condition` 회복량 | ×0.9 | ×1.1 | ×1.0 |
| `attachment` 증가량 | ×1.15 | ×1.0 | ×0.9 |
| `attachment` 감소량 | ×1.2 | ×0.9 | ×1.0 |
| 엄마 `stamina` 소모 (care·outing 행동) | ×1.1 | ×0.9 | ×1.15 |
| sleep 하위 요소(05_03) 야간 하락 | ×1.3 | ×0.7 | ×1.0 |

- 계수 설계 의도: `sensitive`는 변동성(잃는 것도 얻는 것도 큼), `easygoing`은 안정성, `active`는 엄마 체력 압박과 바깥 세계 보상의 교환.

## 6. JSON

아이 프로필 저장 스키마 예시 (13_JSON 세이브 포맷에 병합):

```json
{
  "child_profile": {
    "child_name": "이한별",
    "child_gender": "female",
    "temperament_seed": "sensitive",
    "personality": {
      "confidence": 50,
      "empathy": 50,
      "independence": 50,
      "expressiveness": 50
    }
  }
}
```
