# 01_03 Target Audience

## 1. 주 타깃 (Primary)

- **20대 후반~40대 한국인** — 육아 당사자이거나, 육아를 앞두고 있거나, 자신의 성장기를 돌아보고 싶은 층.
- 내러티브 게임(Florence, Unpacking, 스토리 중심 인디)에 지불 경험이 있는 플레이어.
- 플레이 세션: 1회 20~40분, 총 플레이 6~10시간을 상정한다.

## 2. 부 타깃 (Secondary)

- 부모와의 관계를 소재로 한 콘텐츠(에세이, 드라마)를 소비하는 비게이머 층.
  - 대응 설계: 조작 난이도 최소화, 실패 상태 없음, 언제든 이어하기 가능한 자동 저장.
- 한국 문화 소재 게임에 관심 있는 해외 플레이어 (v1은 한국어 우선, 영어 로컬라이즈는 v1.5 검토).

## 3. 안티 타깃 (Non-Target)

- 최적화·공략 중심 시뮬레이션을 기대하는 플레이어 — 정답 빌드를 제공하지 않는다.
- 빠른 템포의 보상 루프를 기대하는 플레이어.

## 4. 플랫폼·세션 설계 함의

| 항목 | 결정 | 근거 |
|---|---|---|
| 1차 플랫폼 | PC (Steam) | 내러티브 인디 주 소비 채널 |
| 2차 플랫폼 | 모바일 이식 검토 | 부 타깃(비게이머)의 접근성 |
| 세션 단위 | 게임 내 1일 = 1세션(20~40분) | 끊어 플레이해도 감정선이 유지되는 단위 |
| 난이도 | 게임오버 없음 | 실패가 아닌 결과의 차이만 존재 |

## 5. 민감성 가이드

- 산후우울, 유산, 아동 안전사고 등 무거운 소재는 다루되, 시작 시 콘텐츠 고지를 제공한다.
- 특정 육아 방식(모유/분유, 워킹맘/전업맘)을 정답으로 취급하는 수치 설계를 금지한다. (Pillar 2·4와 연동)
