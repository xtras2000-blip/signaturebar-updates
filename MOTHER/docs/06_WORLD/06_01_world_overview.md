# 06_01 World Overview

무대 설정의 단일 기준 문서. 장소 상세는 06_02, NPC는 06_03, 이벤트 연동은 07_EVENT를 따른다.
본 문서는 카탈로그성 문서로 표 중심으로 구성한다 (7섹션 의무 대상 아님).

## 1. 무대: 한솔마을

수도권 외곽의 소형 아파트 단지. Pillar 2(현실의 무게)·Pillar 3(Korea-first)에 따라
"평범해서 누구나 아는 공간"을 지향한다. 판타지적 미화 금지.

| 항목 | 설정 값 | 비고 |
|---|---|---|
| 단지명 | 한솔마을 (한솔아파트 3단지) | 고유명사. 대사·UI에서 "한솔마을" 표기 고정 |
| 위치 | 수도권 외곽, 서울까지 광역버스 50분 | 남편 출퇴근·복직 압박 이벤트의 물리적 근거 |
| 주거 형태 | 24평(전용 59㎡) 전세, 15년차 구축 | 초기 가계 `money` 3,000,000원 설정과 정합 |
| 구조 | 방 3, 거실, 주방, 욕실 1 | 06_02의 집 내부 5개 `location_id`와 1:1 대응 |
| 층/향 | 7층, 남동향 | 층간소음(아랫집 항의) 이벤트의 전제 |
| 생활권 | 단지 상가 + 마을버스 생활권 | 차 없이도 하루 루프가 성립해야 함 |

## 3. 계절·명절 순환

1게임년 = 현실 1년. 계절과 명절은 이벤트 트리거 조건(`trigger.conditions`)으로 참조한다.
식별자: `season` = `spring | summer | autumn | winter`, `holiday` = 아래 표의 `holiday_id`.

| 시기 | 식별자 | 이벤트 영향 |
|---|---|---|
| 봄 (3~5월) | `season:spring` | 새 학기·입소 시즌. 어린이집/유치원 적응 이벤트 창 개방 |
| 여름 (6~8월) | `season:summer` | 장마·열대야로 `child_condition` 하락 압력. 수족구 유행 |
| 가을 (9~11월) | `season:autumn` | 운동회·소풍. CH3 비교(`comparison`) 계열 이벤트 밀도 상승 |
| 겨울 (12~2월) | `season:winter` | 독감철. 소아과 방문 빈도 상승, `money` 지출 증가 |
| 설날 | `holiday:seollal` | 시댁 방문 의무 이벤트. 시어머니 갈등 축 활성화 |
| 추석 | `holiday:chuseok` | 양가 이동. `stamina` 대량 소모, 명절 후유증 후속 이벤트 |
| 어린이날 | `holiday:childrens_day` | 지출 이벤트 + 또래 비교 소재 |
| 아이 생일 | `holiday:child_birthday` | CH1 돌잔치를 시작으로 매년 회귀. `memory_log` 회수 연출의 정기 앵커 |

- 명절 이벤트는 `scheduled` 트리거로 고정 발생시키되(D-010), 내용은 누적된 관계 수치·기억에 따라 달라진다 (Pillar 4).
- 계절 조건은 `{"type":"season","value":"winter"}` 형식으로 07_01의 조건 스키마를 따른다.

## 4. 챕터에 따른 공간 변화

같은 집이 아이의 성장에 따라 물성만 바뀐다. 이사 없음 — "공간은 그대로인데 아이만 자란다"가
CH5 상실감(`loss`) 연출의 핵심 장치다. 10_ART는 챕터 전환 시 아래 표를 배경 교체 기준으로 사용한다.

| 챕터 | 거실 (`loc_home_living`) | 안방 (`loc_home_bedroom`) | 작은방 (`loc_home_child_room`) |
|---|---|---|---|
| CH1 (0~12개월) | 매트 + 젖병소독기 + 빨래 건조대 상시 | 아기 침대가 부부 침대 옆 점유 | 창고 (선물받은 육아용품 박스) |
| CH2 (1~3세) | 범퍼 매트 전면 + 장난감 수납장 | 아기 침대 퇴장, 가족 침대화 | 기저귀·옷 수납 + 낮잠 공간 |
| CH3 (3~5세) | 그림책 책장 + 벽면 낙서 흔적 | 부부 공간 일부 회복 | 유아 책상·의자 입장, "아이 방" 호칭 시작 |
| CH4 (5~6세) | 보드게임·학습지 등장 | 밤중 "혼자 자기" 갈등의 무대 | 아이 취향의 방 (본인이 고른 이불) |
| CH5 (6~7세) | 책가방·입학 준비물 코너 | 부부만의 공간으로 복귀 | 초등 입학 책상 배치, 아기용품 완전 퇴장 |

- 퇴장하는 사물(아기 침대, 젖병소독기)은 버리는 연출을 1회 이벤트로 소비한다 — 물건의 퇴장이 곧 감정 비트다 (Pillar 1).
- 공간 상태는 저장 데이터가 아니라 `chapter` 값에서 파생한다 (12_DATABASE에 파생 규칙만 기록).
