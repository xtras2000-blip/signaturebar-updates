# 06_03 NPC Cast

NPC 카탈로그의 단일 기준. 카탈로그성 문서로 표 중심 구성 (7섹션 의무 대상 아님).
대사 톤은 08_DIALOGUE, 관계 수치의 변화식은 03_GAME_SYSTEM에서 정의한다.

## 1. 식별자 규칙

- `npc_id` 명명: `npc_{역할}` 영어 snake_case. 고유명(이름)은 표시용, 참조는 항상 `npc_id`.
- 관계 수치: `rel_{npc_id}` (0~100, init 50). 관계 수치를 갖는 NPC만 해당 (표의 "관계 수치" 열).
  - 예: 남편의 관계 수치 키는 `rel_npc_husband`.
- 관계 수치는 이벤트 `effects`로만 변화한다. 신규 수치이므로 D-003에 따라 DECISION_LOG 승인 대상으로 표기해 둔다 (제안 상태).
- 아이(`child`)는 NPC가 아니라 핵심 개체다 (00_04). 본 카탈로그에 포함하지 않는다.

## 2. NPC 카탈로그

| npc_id | 이름 | 관계 | 등장 챕터 | 역할 | 갈등 축 | 관계 수치 |
|---|---|---|---|---|---|---|
| `npc_husband` | 박지훈 | 남편 | CH1~CH5 | 공동 양육자이자 최대 갈등·화해 상대 | 육아 분담 vs 야근, "도와준다"는 말의 온도 차 | O (`rel_npc_husband`) |
| `npc_mother_in_law` | 정순자 | 시어머니 | CH1~CH5 | 구세대 육아관의 대변자, 명절 이벤트 축 | 훈육·먹이기 방식 개입 vs 선 긋기 | O (`rel_npc_mother_in_law`) |
| `npc_grandma` | 김영숙 | 친정엄마 | CH1~CH5 | 무조건적 지원군, 그러나 KTX 2시간 거리 | 딸 걱정 vs 본인 건강 악화(후반) | O (`rel_npc_grandma`) |

| `npc_pediatrician` | 한정우 | 소아과 원장 | CH1~CH5 | 담담한 전문가, 과잉 불안을 눌러주는 앵커 | 없음 (안정 장치 역할) | X |
| `npc_boss` | 강미란 | 직장 팀장 | CH1~CH5 | 복직 압박과 조직의 현실을 전달 | 육아휴직 눈치 vs 커리어 인정 | O (`rel_npc_boss`) |

## 3. 서사 아크

| npc_id | 아크 (1~2줄) |
|---|---|
| `npc_husband` | CH1 "몰라서 못 하는 남편"에서 갈등이 누적되고, CH4에서 큰 다툼과 화해를 거쳐 CH5 입학식에 나란히 서는 것으로 완결. `rel_npc_husband` 누적치가 화해 장면의 대사 분기를 결정. |
| `npc_mother_in_law` | 명절마다 개입의 강도가 시험대에 오른다. 플레이어가 선을 그은 기억(`memory_log`)이 CH4에서 "네 방식대로 잘 키웠다"는 인정 또는 침묵으로 회수. |
| `npc_grandma` | CH1 산후우울 시기의 버팀목. CH4~5에 본인 건강 이슈가 드러나며 "돌봄을 받던 딸이 돌보는 딸이 되는" 역전을 겪는다. |
| `npc_cohort_sunny` | 유일하게 "나만 힘든 게 아니구나"를 주는 관계. 복직 이후 소원해졌다가 CH5 초등 배정에서 재회, 고립감(`isolation`) 해소의 열쇠. |
| `npc_cohort_yujin` | 정보와 비교를 동시에 주는 양가적 존재. CH3 비교 불안(`comparison`)의 주 트리거였다가, CH4에서 본인의 힘듦을 고백하며 입체화. |
| `npc_daycare_teacher` | CH2 분리불안 시기의 조력자. 상담 이벤트 선택 누적이 아이의 기관 적응 연출과 `independence` 형성에 반영. |
| `npc_pediatrician` | 아크 없는 고정점. 접종·검진마다 같은 자리에서 아이의 키가 자라는 것을 측정해 주는 "시간의 눈금" 역할. |
| `npc_boss` | CH1 복직 압박의 발신자. 복직 후 조퇴·눈치 갈등을 지나 CH5에서 플레이어의 선택 누적에 따라 인정 또는 결별(이직)로 갈린다. |
| `npc_neighbor` | 층간소음 항의(CH1~2)로 최악에서 시작. 엘리베이터 인사의 누적으로 CH5 "학교 잘 다녀와라" 한마디에 도달하는 느린 반전 아크. |
| `npc_peer_doyun` | CH3 장난감 다툼 → CH4 절교 소동 → CH5 같은 반 배정. 아이의 `empathy`·`expressiveness` 선택이 이 관계의 장면 연출을 바꾼다. |
| `npc_peer_hayul` | "하율이는 벌써 걷는대" 비교의 대상에서, CH5 나란히 입학하는 친구로 전환 — 비교가 동행으로 바뀌는 것이 주제 회수. |
| `npc_school_teacher` | 단일 챕터 등장. 예비소집일에 아이 이름을 처음 "학생"으로 불러 CH5 떠나보냄(`letting_go`)을 촉발한다. |

## 4. 관계 수치 밴드별 간접 표현

`rel_*` 값은 숫자로 노출하지 않고(D-004) 아래 밴드에 따라 대사 톤·행동 패턴을 전환한다. 08_DIALOGUE의 톤 분기 기준.

| 밴드 | 범위 | 표현 방식 (예: `npc_husband`) |
|---|---|---|
| 냉랭 | 0~19 | 단답, 시선 회피, 메신저로만 대화 ("응", "알아서 해") |
| 서먹 | 20~39 | 용건 중심 대화, 육아를 "돕는 일"로 지칭 |
| 보통 | 40~59 | 일상 대화 성립, 감정 화제는 회피 |
| 가까움 | 60~79 | 먼저 묻는 말이 생김 ("오늘 힘들었지"), 자발적 분담 |
| 깊음 | 80~100 | 말 없이 통하는 장면 허용, 회수 연출에서 최상위 대사 분기 해금 |

## 5. 대사 톤 가이드 (08_DIALOGUE 발주 기준)

| npc_id | 기본 말투 | 금지 |
|---|---|---|
| `npc_husband` | 무던하고 눈치 없는 존대 없는 구어 | 악역화 (게으름이 아니라 몰라서 못 하는 인물) |
| `npc_mother_in_law` | 애정과 개입이 섞인 명령형 ("애는 그렇게 키우면 안 돼") | 희화화, 일방적 악역화 |
| `npc_grandma` | 걱정 많은 사투리 섞인 다정함 | 신파 과잉 |
| `npc_cohort_sunny` | 반말, 자조 섞인 유머 ("우리 애만 안 자는 줄") | 설명조 위로 |
| `npc_cohort_yujin` | 정보 용어가 많은 빠른 말 ("그거 대기 걸어놨어?") | 노골적 악의 (비교는 항상 호의의 탈을 쓴다) |
| `npc_daycare_teacher` | 절제된 존댓말, 관찰 기반 보고 | 평가·판정 어투 |
| `npc_pediatrician` | 짧고 건조한 사실 전달 ("열은 내일까지 갑니다") | 과장된 친절 |
| `npc_boss` | 배려의 형식을 갖춘 압박 ("천천히 생각해요, 근데 다음 주까지") | 대놓고 위법적인 발언 |
| `npc_neighbor` | 무뚝뚝한 통보체에서 점차 안부형으로 이동 | 급격한 태세 전환 |
| `npc_peer_doyun` / `npc_peer_hayul` | 유아 어휘, 문법 오류 허용 | 어른스러운 대사 |
| `npc_school_teacher` | 공적이고 따뜻한 안내문 어투 | 개별 서사 개입 |

## 6. 운용 규칙

- NPC 등장 이벤트는 등장 챕터 이전에 참조 불가 (15_QA 자동 체크, 06_02 장소 규칙과 동일).
- 관계 수치 보유 NPC(O)만 `effects`에 `rel_*` 키 사용 가능. 미보유 NPC(X)는 `memory_log`로만 흔적을 남긴다.
- 관계 수치는 감정 장면에서 UI에 노출하지 않는다 (D-004). NPC의 말투·행동 변화로만 간접 표현.
- 신규 NPC는 본 문서 등록 후 사용 (00_04 표기 규칙 상속).
