# 00_01 Project Overview

## 1. 프로젝트 정의

- **프로젝트명**: MOTHER
- **장르**: 현실 기반 육아 내러티브 시뮬레이션
- **배경**: 현대 한국 (대도시 외곽의 소형 아파트 단지)
- **플레이어 역할**: 아이를 키우는 엄마
- **핵심 경험**: 아이의 성장 과정에서 발생하는 선택과 그 감정적 결과를 체험

## 2. 핵심 루프

1. **하루 시작**: 시간·체력·가계 자원이 갱신된다.
2. **일과 선택**: 돌봄, 가사, 일, 자기 돌봄 중 시간 블록을 배분한다.
3. **이벤트 발생**: 아이 상태·세계 상태·확률 조건에 따라 이벤트가 트리거된다.
4. **대화/선택**: 선택지가 아이의 스탯, 관계도, 기억 로그에 반영된다.
5. **하루 마감**: 변화 요약이 표시되고 저장 데이터가 갱신된다.

## 3. 제작 원칙 (PROJECT_RULES.md 상속)

- Emotion first: 모든 시스템은 감정 전달을 목적으로 설계한다.
- Realism over fantasy: 판타지 요소 없이 현실의 디테일로 승부한다.
- Korea-first: 한국의 육아 현실(돌잔치, 어린이집 대기, 육아휴직 등)을 1차 소재로 한다.
- 모든 메커닉 문서는 Purpose / Variables / State machine / UI / Database / JSON / QA 7개 항목을 반드시 포함한다.
