# 11_01 Sound Direction

## 1. 원칙

1. **다이어제틱 우선 (Pillar 2)**: 기본 사운드스케이프는 현실 생활음이다 — 젖병 소독기, 세탁기 종료음, 아파트 층간 소음, 놀이터 소음, 밥솥 증기음. 화면 안에 음원이 존재하지 않는 소리는 원칙적으로 재생하지 않는다.
2. **BGM은 감정 장면에만**: 01_04 §2 우선순위에서 음악은 4순위다. 아이의 행동·일상의 변주·대사가 감정을 전달한 뒤에만 음악이 개입한다. 평시 블록 배분·일상 루프에서는 BGM 없음(앰비언스만). BGM 트리거는 11_02 §3의 `emotion_tags` 규칙을 따른다.
3. **슬픔 강요 금지 (01_04 §3)**: 음악 고조로 감정을 밀어붙이지 않는다. 크레셴도 상한: 감정 장면 내 +6dB. 스트링 스웰 단독 사용 금지.
4. **침묵의 설계**: 무음도 설계 대상이다.
   - CH1 새벽 수유 장면(`ch1_ev_night_feeding`, 02_02): BGM·앰비언스 전부 무음. `sfx_clock_wall_tick`(벽시계 초침)과 아기 삼키는 소리만 재생. `wonder` 태그 성립 시에만 종료 직전 3초간 `motif_lullaby` 허밍(11_02)이 페이드인.
   - CH4 화해 직전 침묵: 대사 사이 무음 최소 2초 보장. 시스템이 자동으로 채우지 않는다.
   - `isolation` 태그 장면: 앰비언스에서 사람 소리 성분만 제거하고 기계음(냉장고 험, 시계)만 남긴다.

## 2. 사운드 카테고리·명명 규칙

| 프리픽스 | 카테고리 | 형식 | 예시 |
|---|---|---|---|
| `sfx_` | 단발 효과음(생활음·동작음·UI음) | `sfx_{source}_{action}` | `sfx_bottle_shake`, `sfx_door_apt_close`, `sfx_ui_confirm` |
| `amb_` | 앰비언스 루프 | `amb_{location}_{time_block}` | `amb_livingroom_night`, `amb_playground_midday` |
| `bgm_` | 음악 트랙 | `bgm_ch{n}_{motif}_{variant}` | `bgm_ch1_lullaby_hum`, `bgm_ch5_lullaby_orch` |

- `{time_block}`은 02_02 enum(`morning`/`midday`/`afternoon`/`evening`/`night`) 그대로 사용. UI음은 별도 프리픽스 없이 `sfx_ui_` 서브네임스페이스로 관리한다.
- 아기 발성은 `sfx_child_` 하위: `sfx_child_cry_fussy_01` 등(§4).

## 3. 볼륨 버스 구조

| 버스 | 부모 | 기본 레벨 | 내용 |
|---|---|---|---|
| `bus_master` | — | 0dB | 최상위 |
| `bus_amb` | master | −12dB | `amb_` 전체. 감정 장면에서 −6dB 추가 덕킹 |
| `bus_sfx` | master | −6dB | 생활음·동작음 |
| `bus_sfx_child` | bus_sfx | 0dB (상속) | 아기 발성 전용 자식 버스. 울음은 덕킹 대상에서 제외(항상 들려야 함) |
| `bus_ui` | master | −10dB | `sfx_ui_` |
| `bus_bgm` | master | −10dB | `bgm_` 전체. 평시 뮤트, 감정 장면에서만 활성 |

- 덕킹 규칙: `bus_sfx_child`에 신호가 있으면 `bus_amb` −4dB, `bus_bgm` −3dB 사이드체인. 아기 울음은 어떤 연출로도 가려지지 않는다(압도됨 감정의 핵심 소재).
- 옵션 메뉴 노출은 master/bgm/sfx/amb 4개 슬라이더만. 내부 버스는 노출하지 않는다(09_UI).

## 4. 아기 울음 사운드 설계

울음은 CH1~CH2의 1차 정보 채널이다. 플레이어는 수치 UI 없이(D-004) 울음 유형을 소리로 구분해 원인을 추론해야 한다 — "행동으로 수치를 간접 표현"의 청각판.

| 울음 유형 | 식별자 | 기본 피치 | 리듬 패턴 | 강도 곡선 | 주 트리거(03_01 연동) |
|---|---|---|---|---|---|
| 짜증(칭얼) | `cry_fussy` | 낮음 (F4 중심) | 불규칙, 끊김 많음, 사이 옹알이 혼입 | 평탄, 자연 감쇠 | 졸림·과자극. child_condition 40~70 구간 |
| 배고픔 | `cry_hunger` | 중간 (A4 중심) | 규칙적 반복 "왜-왜-왜", 리듬 일정 | 시간에 따라 계단식 상승 | meal_score 0인 블록 경과 시 |
| 아픔 | `cry_pain` | 높음 (C5 이상) | 긴 비명 후 무호흡 정지 → 재폭발 | 급상승 후 고원 유지 | child_condition < 40 (병원 이벤트 조건과 동일 문턱) |

- 각 유형은 `_01`~`_03` 3테이크를 라운드로빈 재생해 반복감을 없앤다. 파일명: `sfx_child_cry_{type}_{take}`.
- 파라미터 규격: 피치 랜덤 ±50cent, 재생 간격 지터 ±15%, `cry_pain`만 지터 0(규칙성이 이질감·긴급함을 만든다).
- 방치 시 에스컬레이션: `cry_fussy` → 3분(게임 내 시간) 경과 시 `cry_hunger` 강도 곡선 차용 → 유형 자체는 불변(원인 추론 학습을 깨지 않기 위해).
- 달래기 성공 시 크로스페이드 2초로 훌쩍임(`sfx_child_sob_calm`)을 경유해 정지. 즉시 컷 금지.
- CH3 이후 울음 빈도는 급감하고 `sfx_child_` 채널은 발화·웃음 중심으로 전환된다(대사 소유는 08_DIALOGUE).

## 5. 대표 생활음 리스트 (제작 우선순위 P0)

Pillar 3(Korea-First)의 청각 구현. 아래는 챕터 공통 P0 목록이며 전체 목록은 12_DATABASE 에셋 테이블에서 관리한다.

| 파일명 | 내용 | 사용처 |
|---|---|---|
| `sfx_ricecooker_steam` | 밥솥 증기·취사 완료 멜로디 | morning 실내 공통 |
| `sfx_intercom_apt` | 아파트 관리사무소 안내 방송(먹먹한 스피커 톤) | midday, `isolation` 장면의 유일한 외부인 목소리 |
| `sfx_washer_end` | 세탁기 종료 알림음 | housework 블록 |
| `sfx_stroller_wheel` | 유모차 바퀴·보도블럭 덜컹임 | outing 블록 |
| `amb_apt_night` | 냉장고 험 + 보일러 배관음 + 간헐적 윗집 발소리 | night 실내 기본 앰비언스 |
| `amb_playground_midday` | 놀이터 아이들 소리(원경), 매미(여름 배리언트) | CH3 야외 |
| `sfx_clock_wall_tick` | 벽시계 초침 | 무음 설계 장면 전용(§1-4) |

- 라우드니스 규격: 앰비언스 −28 LUFS, 생활음 단발 −20 LUFS, 아기 울음 −16 LUFS(최우선 가청), BGM −18 LUFS. 포맷: 48kHz/24bit WAV 원본, 빌드 시 OGG 변환.
