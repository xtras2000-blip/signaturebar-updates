# 09_01 UI Principles

가이드 문서. D-004("감정 장면에서 UI 수치 숨김. 수치는 행동·연출로 간접 표현")의 구현 원칙과, 부 타깃 비게이머(D-002·01_03)를 위한 접근성 기준을 정의한다. 화면 흐름은 09_02, 위젯별 명세는 09_03이 소유한다.

## 1. 원칙 5개조

1. **숫자보다 상태.** 정확한 숫자 대신 상태 아이콘·행동 연출로 보여준다. 숫자를 읽는 순간 감정이 계산이 된다(Pillar 1).
2. **감정 장면에서 HUD는 사라진다.** 이벤트 `scenes` 재생 중 수치 UI 완전 숨김(D-004).
3. **한 번의 클릭으로 충분하다.** 모든 핵심 진행은 클릭 1회. 더블클릭·드래그·홀드·콤보 입력을 요구하지 않는다.
4. **실수는 벌하지 않는다.** 게임오버가 없듯(D-002) UI도 실수를 복구 가능하게 설계한다.
5. **읽을 수 있어야 게임이다.** 비게이머·장년 플레이어 기준의 텍스트 크기·대비를 하한선으로 삼는다.

## 2. 수치 노출 최소화 설계 (수치 → 간접 표현 매핑)

| 수치 | 평시 표현 | 숫자 노출 허용 지점 |
|---|---|---|
| `attachment` | 아이 행동 세트(`secure`/`neutral`/`distant`, 03_01·05_CHILD) | 없음 (전 구간 숫자 금지) |
| `child_condition` | 아이 행동 애니메이션(생기/처짐), 낮잠·식사 반응 | 없음 |
| `stamina` | 화면 가장자리 톤 다운(09_03 `wgt_stamina_vignette`) | 없음 |
| `mind` | 엄마 초상화 표정 3단계(09_03 `wgt_portrait_player`) | 없음 |
| `money` | HUD에는 가계부 아이콘만 | 가계부 화면(`ovl_ledger`)에서만 원화 숫자 |
| 성격 축 4종 | 이벤트·대사 변형으로만 체감 | 없음 (문장형 코멘트만, 03_01 UI 절) |

- 03_01 UI 절의 "아이콘+게이지"는 눈금·수치 라벨 없는 **상태 게이지**(3단계 색·형태)로 구현한다. 게이지에 숫자·퍼센트 표기 금지.

## 3. HUD 모드와 페이드아웃 규칙

| `hud_mode` | 적용 화면(09_02) | 내용 |
|---|---|---|
| `full` | `scr_block_allocation`, `scr_day_start` | 상태 아이콘·시간 블록 바 표시 |
| `minimal` | `scr_block_play` 평시 | 시간 블록 바만 유지 |
| `hidden` | 이벤트 `scenes` 재생, `scr_chapter_montage` | 모든 HUD 숨김(D-004) |

- 전환 연출: `full/minimal → hidden`은 0.5초 페이드아웃, 복귀는 1.0초 페이드인(감정 여운 우선, 급격한 UI 복귀 금지).
- `hidden` 중에도 일시정지(`ovl_pause`)와 백로그(08_01)는 입력 가능 — 접근성상 탈출구는 항상 열어 둔다.
- 감정 장면 중 발생한 수치 변화는 복귀 후에도 토스트·팝업으로 알리지 않는다(03_01 UI 절). 변화는 연출과 `day_end_summary` 문장으로만 회수한다.

## 4. 접근성 — 비게이머 타깃

### 4.1 원클릭 조작

| 행동 | 입력 |
|---|---|
| 대사 진행 | 화면 아무 곳 클릭 / 스페이스 (08_01) |
| 블록 배분 | 블록 칸 클릭 → 행동 카드 클릭 (2클릭 = 2결정, 결정당 1클릭) |
| 선택지 확정 | 선택지 클릭 1회 |
| 모든 화면 | 마우스만으로 완주 가능. 키보드는 보조 수단 |

### 4.2 실수 복구

| 상황 | 복구 규칙 |
|---|---|
| 블록 배분 중 | 확정 전 무제한 재배치. 확정 버튼은 별도(오클릭 방지 위해 카드와 이격 배치) |
| 블록 확정 직후 | 해당 블록 시작 전까지 "다시 배분" 1회 허용 |
| 이벤트 선택지 | 되돌리기 없음(Pillar 4 — 선택은 쌓인다). 대신 선택지 클릭 후 0.3초 입력 잠금으로 연타 오입력 방지 |
| 지출 발생 선택지 | 금액이 `text_kr`에 포함된 경우에 한해 확인 문구 1회 (숫자 노출 예외는 money뿐이므로 허용) |
| 세이브 | autosave(매일, 02_GAME_DESIGN 루프) + 수동 저장. 덮어쓰기 전 확인 1회 |

### 4.3 기타

- 신규 용어(시간 블록 등)는 첫 등장 시 1회 인라인 설명. 튜토리얼 전용 화면을 만들지 않는다(일상 속에서 배운다).
- 모든 인터랙션 요소는 최소 48×48px 히트 영역.

## 5. 텍스트·컬러 기준

| 항목 | 기준 (1920×1080 기준) |
|---|---|
| 대사 텍스트 | 최소 24px, 줄 간격 1.5 |
| UI 라벨·버튼 | 최소 20px |
| 텍스트 크기 옵션 | 100% / 125% / 150% 3단계, 전 화면 즉시 반영 |
| 명도 대비 | 텍스트 대 배경 4.5:1 이상 (WCAG AA) |
| 색 부호화 | 색만으로 상태 구분 금지 — 색+형태(아이콘 실루엣) 이중 부호화 |
| 색약 대응 | 적록 구분 의존 금지. 상태 3단계는 명도 차로도 구분 가능해야 함 |
| 폰트 | 본문 고딕 1종 + 손글씨(기억·앨범 연출) 1종, 총 2종 이내 |

## 6. 좋은 예 / 나쁜 예

| 나쁜 예 | 좋은 예 | 근거 |
|---|---|---|
| "애착도 +5" 플로팅 텍스트 | 아이가 먼저 팔을 벌린다 | D-004, §2 |
| stamina 게이지에 "34/100" 라벨 | 화면 가장자리가 한 단계 어두워진다 | §2 |
| 감정 장면 종료 후 변화량 팝업 | 다음 날 아침 연출의 미세한 변주 | §3 |
| 선택지 hover 시 effects 미리보기 | 선택지는 문장만 보여준다 | Pillar 1 |
| 실수 클릭 즉시 확정 | 0.3초 입력 잠금 + 배분은 재배치 허용 | §4.2 |
