# MOTHER Prompt Book v2 — UI 소스·화면별 에셋

프로토타입 화면(1~7단계)에 필요한 이미지 소스 전체. 사용 규칙은 10_03·prompt_book(v1)과 동일하다. 로고·버튼의 **글자는 AI로 만들지 않는다** — 텍스트는 게임 폰트로 얹고, AI는 글자 없는 소스만 생성한다.


## A. 브랜드 — 앱 아이콘·스플래시
