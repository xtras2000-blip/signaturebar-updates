# MOTHER Prompt Book v1 — 수직 슬라이스 (CH1 4일)

AI 실사 생성(D-023, 10_03) 프롬프트 정본. 장면 프롬프트는 반드시 [공통 스타일] + [고정문] + [컷별 내용] + [네거티브] 조립으로만 사용한다. 고정문 수정은 DECISION_LOG 등재 후에만 허용.

## 0. 공통 블록

**공통 스타일 (모든 프롬프트 앞에 붙임)**
> 한국 다큐멘터리 스타일의 실사 사진. 자연광, 저채도, 차분하고 절제된 색감, 생활감 있는 디테일. 세로 구도 3:4. 새벽의 청회색 기운이 남아 있는 색 온도(챕터1 그레이딩 기준).

**네거티브 (모든 프롬프트 끝에 붙임)**
> 다음을 포함하지 말 것: 화보/광고 느낌, 과도한 보정, 고채도, 서양식 주택 인테리어, 실내에서 신발 신은 모습, 연예인을 닮은 얼굴, 브랜드 로고, 화면 속 텍스트, 워터마크, 일러스트/수채화 느낌.

**인물 고정문 — 엄마 (`player`)**
> 30대 중반의 평범한 한국 여성. 어깨 길이 머리를 낮게 대충 묶음, 화장기 없는 얼굴, 피곤한 기색. 회색 맨투맨과 편한 바지 차림(실내), 외출 시 무채색 패딩. 마르지도 화려하지도 않은 현실적인 체형.

**인물 고정문 — 아기 (`child_age0`)**
> 생후 1~2개월의 한국 아기. 배냇저고리 또는 흰색·미색 내복 차림. 머리숱 적음. 통통한 볼.

**장소 고정문 — 거실 (`loc_home_living`)**
> 한국 수도권의 15년 된 24평 아파트 거실. 옅은 마루 바닥, 벽걸이 아님 스탠드형 TV, 접이식 빨래 건조대, 아기 매트, 젖병 건조대, 육아용품이 생활감 있게 흩어져 있음. 좁지만 정돈하려 애쓴 흔적.

**장소 고정문 — 안방 (`loc_home_bedroom`)**
> 같은 아파트의 안방. 바닥 매트리스 또는 낮은 침대, 아기 침대가 붙어 있음, 수유등(낮은 주황색 조명), 가습기, 쌓인 육아용품 상자.

## 5. 운영 규칙 요약

1. 생성 순서: §1 REF 시트 확정 → §2 공간 컷 → §3 일상 컷 → §4 감정 정점.
2. 컷당 4안 이상 생성 후 선별. 원판은 `assets/raw/`에 보존(폐기 금지).
3. 선별 기준: 10_03 §6 QA — 인물 일관성 / 한국 정합("우리 집 같다") / 세로 구도에서 하단 대사 영역 비충돌.
4. 후처리: 10_01 §3 — `pal_ch1_dawn` 그레이딩 + 그레인 6~8% 후 `assets/final/` 등록.
5. 파일마다 생성 도구·일시·사용 프롬프트를 `*.meta.json`으로 기록 (10_03 §5 권리 입증).
