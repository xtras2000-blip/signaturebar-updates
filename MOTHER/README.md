# MOTHER — Game Bible

현대 한국을 배경으로, 엄마가 아이를 0세부터 초등학교 입학까지 키우는 내러티브 시뮬레이션.
이 폴더는 프로젝트의 단일 진실 원천(single source of truth)이다.

## 운영 문서

| 파일 | 역할 |
|---|---|
| `CLAUDE.md` | Claude Code 시스템 프롬프트 (역할·미션) |
| `PROJECT_RULES.md` | 제작 원칙과 메커닉 문서 7항목 규격 |
| `STYLE_GUIDE.md` | 문서 스타일 규칙 |
| `TASK_QUEUE.md` | 작업 순서와 진행 상태 |
| `DECISION_LOG.md` | 모든 주요 결정의 기록 (D-001~) |

## 바이블 목차 (docs/)

| 번호 | 디렉터리 | 내용 |
|---|---|---|
| 00 | PROJECT | 개요, 범위·마일스톤(M1~M6), 문서 파이프라인, 용어집 |

| 02 | GAME_DESIGN | 코어 루프, 시간 블록 시스템, 챕터 구조, 엔딩 시스템 |
| 03 | GAME_SYSTEM | 수치 시스템, 자원 경제, 기억 로그, 저장 시스템 |

## 읽는 순서

1. 처음 온 사람: `01_VISION` → `00_PROJECT/00_04_glossary.md` → `02_GAME_DESIGN`
2. 시스템 구현자: `03_GAME_SYSTEM` → `12_DATABASE` → `13_JSON` → `14_AI`
3. 콘텐츠 작성자: `07_EVENT/07_02_event_authoring_guide.md` → `08_DIALOGUE` → `01_VISION/01_04`

## 불변 규칙 요약

- 게임오버 없음. 선택의 누적 결과만 존재한다. (D-002)
- 모든 이벤트는 `emotion_tags` 필수. (D-005)
- 감정 장면에서 수치 UI를 숨긴다. (D-004)
- 정답 선택지를 만들지 않는다. (Pillar 1·2)
- 폐기 문서는 삭제하지 않고 `99_ARCHIVE`로 이동한다.
